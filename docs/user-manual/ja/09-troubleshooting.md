## 「WebGPUを利用できません」

**意味:** AIを動かすのに必要なグラフィックスチップを、ブラウザがアプリに使わせることができません。

1. **対応ブラウザを使う:** パソコンのChrome 121以降またはEdge。Appleのデバイスでは、macOS 14 / iOS 17以降に更新してSafariを使います。
2. **ブラウザを最新版に更新する。**
3. **ハードウェアアクセラレーションをオンにする。** ChromeまたはEdgeの設定を開き、*ハードウェア アクセラレーション*（*hardware acceleration*）で検索し、**グラフィック アクセラレーションが使用可能な場合は使用する**（*Use graphics acceleration when available*）をオンにして、ブラウザを再起動します。
4. **Android版Chromeの場合:** `chrome://flags` を開き、**WebGPU** で検索して有効にし、Chromeを再起動します。
5. **グラフィックスドライバーを更新する**（Windowsでは、Windows UpdateまたはGPUメーカーのWebサイトから）。
6. **[webgpureport.org](https://webgpureport.org) でデバイスを確認する。** WebGPUに対応していないと表示された場合は、別のブラウザかデバイスを試してください。

その後、エラー画面の **もう一度試す** をタップします。

## ダウンロードが遅い、または失敗する

1. **接続を確認する。** モデルは大きい（1〜8 GB）ので、できればWi‑Fiを使ってください。
2. ダウンロードが終わるまで**タブを開いたまま**にし、デバイスをスリープさせないでください。
3. **「このモデルをダウンロードするための空き容量が足りません」と表示された？** **プライベート（シークレット）ウィンドウ**では、ブラウザが許すストレージはモデルに必要な量よりはるかに少なくなります。通常のウィンドウでアプリを開いてください。そうでない場合は空き容量を増やしてください。[ストレージが足りない](#ストレージが足りない)をご覧ください。モデルが収まりそうにないときは、モデル選択と **モデルをダウンロードしますか？** の確認で事前に警告が出ます。ブラウザが許す容量は **設定 → このデバイス → ストレージ** で確認できます。
4. **もう一度試す。** モデルメニューからもう一度モデルを選びます。前にキャンセルしていた場合は、ダウンロードの確認がもう一度表示されますが、これは正常です。
5. 接続やストレージが限られている場合は、**小さいモデルを選んでください**。

## 返信がとても遅い

AIはお使いのデバイスで動くため、速さはハードウェアとモデルの大きさで決まります。

1. ツールバーの上の**速さの表示**を見ます。小さいモデルが提案されていたら、その名前をタップして切り替えます。
2. **小さいモデルを選ぶ**（モデル選択の *高速* など）。[モデルを選ぶ](06-models.md)をご覧ください。
3. **考える機能をオフにする。** **設定 → 返信** で **推論モデルに先に考えさせる** を **オフ** にします。
4. 特にゲーム、動画編集ソフト、GPUを使う他のAIツールなど、**重いアプリやブラウザのタブを閉じる**。
5. **ノートPCを電源につなぐ。** バッテリー駆動中は、多くのノートPCが省電力のためグラフィックスチップを遅くします。
6. **読み込み後の最初の返信**は、モデルの準備運動のため遅いことがよくあります。その後の返信は速くなります。

## 返信が意味不明、または同じ言葉を繰り返す

例: *"outer outer outer outer…"*、または **「返信を生成中…」が続くのに画面に何も表示されない**（中身が空行や見えない文字のことがあります）。

**意味:** お使いのグラフィックスチップが、速い16ビット演算を正しく行えていません。一部のGPUやドライバーで知られている問題で、デバイスの故障ではありません。

1. **このモデルはお使いのGPUでは動きません**（または **このモデルはお使いのGPUで正しく動かない可能性があります**）というダイアログが表示されたら、**モデルを切り替える** をタップします。動作する32ビット版が選ばれます。
2. 表示されない場合は、モデルメニューを開き、16ビットではなく **32-bit** と表示されたモデルを選びます。
3. ブラウザやグラフィックスドライバーを更新した後は、16ビットモデルをもう一度試せます: **設定 → このデバイス → チェック結果を消去**。
4. **プライベート（シークレット）ウィンドウ**ではストレージが空の状態で始まるため、このデバイスで16ビットモデルが失敗したことをアプリが覚えておらず、もう一度選ぶことがあります。その場合も、読み込み後や最初の返信でのチェックで検出されます。

アプリは、同じ言葉の繰り返しや読めない（見えない場合も含む）出力になった返信も止め、何が起きたかを説明し、あとでモデルが混乱しないよう会話から除外します。

## 返信が途中で切れる

| 表示 | 対処 |
|---|---|
| *最大トークン数で打ち切りました* | **続ける** をタップします。もっと長い返信にしたい場合は、[設定](07-settings.md#最大トークン数)で **最大トークン数** を上げます。 |
| *停止: モデルが1分間書かなくなりました。* | **続ける** または **再生成** をタップします。よく起きる場合は、小さいモデルを使ってください。 |
| *返信が同じことを繰り返し始めたため…* | **再生成** をタップするか、質問の仕方を変えます。詳細なサンプリングの **繰り返しペナルティ** を少し上げるのも効果があります。 |

## 回答の質が低い、または間違っている

デバイス上で動くモデルは大きなオンラインAIサービスよりずっと小さいため、知識が少なく、間違いも多くなります。

1. デバイスが対応できるなら、**大きいモデルを試す**（モデル選択の バランス や 高性能）。
2. 事実についての質問には **的確 ペルソナを使う**。推測するより「わかりません」と答えるよう指示されています。
3. より焦点の定まった回答にするには、**温度を下げる**（例: 0.3）。
4. **質問を詳しくする。** 欲しい形式も伝えます。
5. 会話が今の話題から大きくそれていたら、**新しいチャットを始める**。
6. **日本語について:** 日本語の回答は、極小モデルより大きいモデル（Qwen3.5 2B以上）のほうがずっと自然です。
7. 大切な事実は、信頼できる情報源で**必ず確認**してください。

## アシスタントが前に言ったことを忘れた

どのモデルも、一度に「見る」ことのできる会話の量（*コンテキストウィンドウ*）に限りがあります。長いチャットでは、最も古いメッセージが読む範囲から外れます。

1. 次のメッセージで、大事な点をもう一度**伝える**。
2. **設定 → 返信** で **コンテキストウィンドウを大きくし**、**今すぐモデルを再読み込み** をタップします。（大きい値ほどGPUメモリを多く使います。）
3. 新しい話題には**新しいチャットを始める**。

## ドキュメントを添付できない、または回答がドキュメントを無視する

1. **ファイルの種類を確認する:** 対応しているのはPDF、TXT、Markdown（`.md`）だけです。
2. **サイズを確認する:** 既定の上限は50 MBです。**設定 → ドキュメント → アップロードの最大サイズ** で上げられます（200 MBまで）。
3. **スキャンしたPDFは読めません。** マウスで文字を選択できない場合、そのPDFは画像です。先に文字認識（OCR）のあるPDFツールを使うか、テキストを `.txt` ファイルにコピーしてください。
4. **とても長いドキュメント**（約200ページ超）は、上限のところで切られます。
5. **オフラインで初めて大きいドキュメントを添付した？** アプリは小さな検索用ツールを1回だけダウンロードする必要があります。インターネットに接続して、もう一度試してください。
6. **具体的に質問する。** 長いドキュメントでは、アプリは質問に合う部分を探します。ドキュメントに実際に出てくる言葉を使うと、正しい部分が見つかりやすくなります。
7. **正しいチャットか確認する。** ドキュメントは、添付したチャットのものです。

## アプリが停止した、固まった、画面が真っ白になった

アプリはGPUやエンジンのエラーのほとんどから自動で回復します。ブラウザがGPUを取り上げた場合（スマートフォンではバックグラウンドで起こります）は、モデルを再読み込みして質問に答えます。

デバイスのメモリにモデルが大きすぎると、GPUが停止するか、ページ全体が閉じます。その場合アプリは **GPUが停止しました**、または次に開いたときに **ページが予期せず閉じました** と表示します。そのモデルを勝手に再読み込みすることはなく（そのため停止を繰り返すことはありません）、返信が書いた部分を残し、小さいモデル、**もう一度試す**、**別のモデルを選ぶ** を提案します。モデルメニューでは、再び正常に動くまで **⚠ このデバイスで停止しました** と表示されます。

1. **少し待つ。** 回復には数秒かかることがあります。
2. **ページを再読み込みする。** チャットは保存されており、答えのなかった質問は自動でもう一度送られます。
3. **小さいモデルを選ぶ。** 停止は多くの場合、モデルがGPUのメモリに対して大きすぎることを意味します。スマートフォンでは1段階ずつサイズを下げてください（[スマートフォン](06-models.md#スマートフォン)を参照）。
4. **GPUを多く使う他のタブやアプリを閉じる。**
5. 1回の訪問でGPUが2回停止すると、アプリは処理を止めてトラブルシューティング画面を表示します。[上の手順](#webgpuを利用できません)に従ってください。

> **メモ:** 30分使わないと、アプリはGPUメモリを空けるためにモデルを解放します。次のメッセージでデバイスから再読み込みするので、数秒かかります。

## チャットが見つからない

1. **同じブラウザとデバイスですか？** チャットは作成したブラウザに保存されます。ブラウザやデバイスの間では同期されません。移すには[エクスポートとインポート](08-offline-and-backup.md#データのバックアップと移行)を使ってください。
2. **プライベート（シークレット）ウィンドウですか？** そこで作ったチャットは、ウィンドウを閉じると消える場合があります。**設定 → このデバイス → チャットの保存先** を確認してください。
3. **閲覧データを削除しましたか？** 「サイトデータ」や「Cookieとサイトデータ」を削除すると、チャットも消えます。エクスポートしたファイルがあれば、**チャットをインポート** で元に戻せます。
4. **検索する。** チャット一覧を開き、覚えている言葉を **チャットを検索** に入力します。

## オフラインで動かない

1. オンラインのときに**一度アプリを開いて**、アプリ自身を保存させてください。その後 **設定 → このデバイス → オフラインで動作** を確認します。
2. **ダウンロード済みのモデル**（✓ 付き）を使ってください。新しいモデルには接続が必要です。
3. **プライベート（シークレット）ウィンドウ**では、オフライン用のコピーが保存されない場合があります。

## ストレージが足りない

最も容量を使うのはダウンロードしたモデルです（多くの場合、それぞれ数GB）。アプリの使用量とブラウザが許す容量は **設定 → このデバイス → ストレージ** で確認できます。最初のモデルを読み込んだ後、アプリはブラウザにストレージを保持するよう依頼するので、容量が足りなくなってもモデルが削除されにくくなります。許可されるかどうかはブラウザ次第です（同じ行に「ブラウザが保持します」と表示されます）。

1. **先にチャットをエクスポートする:** **設定 → チャットをエクスポート**。
2. ブラウザの設定で `bowo-prasetyo.github.io` のサイトデータを探して削除します。Chromeでは: **設定 → プライバシーとセキュリティ → サイトの設定 → サイト全体に保存されている権限とデータを表示**（*Settings → Privacy and security → Site settings → View permissions and data stored across sites*）。
3. アプリをもう一度開き、モデルを**1つだけ**選んで、チャットをインポートします。

> **重要:** サイトデータを削除すると、アプリが保存した**すべて**（モデル、チャット、ドキュメント、設定）が削除されます。

## まだ解決しない場合

* **設定 → このデバイス** の内容を控えておいてください。問題を説明するときに役立ちます。
* プロジェクトの[GitHubページ](https://github.com/bowo-prasetyo/web-llm/issues)で問題を報告してください。日本語で書いてもかまいません。報告にプライベートなチャットの内容は含めないでください。
