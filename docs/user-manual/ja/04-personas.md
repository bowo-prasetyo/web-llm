# 4. ペルソナ

[← チャットの管理](03-managing-chats.md) · [マニュアルのトップ](README.md) · [次へ: ドキュメント →](05-documents.md)

**ペルソナ**は、アシスタントの*話し方*（口調、詳しさ、重視すること）を決めます。同じ質問でも、ペルソナによって、くだけた答え、1行の答え、整った文章になります。

## 6つのペルソナ

| ペルソナ | 向いている用途 | 依頼の例 |
|---|---|---|
| 💬 **フレンドリー** *（既定）* | 日常の手助けと気軽なおしゃべり | *「ギターを始めるのにいい方法は？」* |
| 🎯 **的確** | 脱線しない、短く事実に基づいた回答。推測するより「わかりません」と答えます。 | *「海面での水の沸点は何度？」* |
| ✍️ **ライター** | メール、メッセージ、エッセイ、物語の下書き、書き直し、推敲 | *「このメッセージをもっと丁寧に書き直して: …」* |
| 💻 **コーダー** | コードを書く、説明する、デバッグする | *「このPythonのループが終わらないのはなぜ？ …」* |
| 💡 **アイデア出し** | アイデアや選択肢を広げる | *「パン屋の名前のアイデアを10個ちょうだい」* |
| 🛠 **カスタム** | 設定で書いた自分だけの指示 | 自分で設定した内容すべて |

組み込みのペルソナはどれも、前に言ったことと矛盾しないように、また、あなたが正しくないことを言ったときは同意するのではなく丁寧に訂正するように指示されています。

組み込みのペルソナはどれも自分の名前が **Hearth** だと知っているので、「名前は？」と聞かれると「Hearth」と答えます。誰が作ったのかと聞かれたら、Hearthはオープンソースのアプリで、返信はデバイス上で動くオープンなAIモデルから生成されていると説明できます。**カスタム** ペルソナはあなたの指示だけを使うので、名前はあなたが付けたもの（または名前なし）になります。

> **メモ:** 組み込みペルソナの指示は英語で書かれています。小さいモデルは英語の指示に最もよく従うためです。指示には「ユーザーの言語で返信する」ことが含まれているので、日本語で書けば日本語で返信します。

## 新しいチャットのペルソナを選ぶ

新しいチャットのウェルカム画面で、ペルソナカードをタップします。カードの下には各ペルソナの **質問の例** もあります。タップするとすぐに送信されます。

## チャットの途中でペルソナを切り替える

ツールバー左側の **ペルソナメニュー**（現在のペルソナのアイコンと名前が表示されています）を使います。

* 新しいペルソナは**次の**メッセージから適用されます。
* それまでの会話はそのまま残ります。
* チャットごとに自分のペルソナを覚えているので、ここで切り替えても他のチャットには影響しません。

## 新しいチャットの既定のペルソナを設定する

1. **設定**（⚙）を開きます。
2. **ペルソナ → 新しいチャットの既定** に進みます。
3. ペルソナを選びます。

ペルソナがどんな指示を受けているかは、そのメニューの下の **…の指示を表示** で確認できます。

## 自分だけのペルソナを作る（カスタム）

**カスタム** ペルソナは、あなたが書いた指示に従います。

1. **設定 → ペルソナ** を開きます。
2. **🛠 カスタムペルソナ** の下のテキスト欄に指示を入力します。
3. チャットに戻り、ペルソナメニューで **🛠 カスタム** を選びます。

変更は次のメッセージから反映されます。再読み込みは不要です。

**良い指示を書くコツ:**

* **短く、わかりやすく。** デバイス上で動く小さいモデルは、長いルールの一覧より、明確な数文のほうがずっとよく従います。
* **役割とやることを書く。** 例:
  > *あなたは10歳の子どもを教える、辛抱強い家庭教師です。簡単な言葉と身近な例で説明し、毎回の答えの最後に、理解を確かめる質問を1つしてください。*
* **避けてほしいこと**は、必要なら1文で: *「専門用語は使わないで。」*
* **言語について:** 小さいモデルは英語の指示のほうがよく従うことがあります。日本語の指示がうまく守られない場合は、英語で指示を書き、*"Reply in Japanese."* を加えてみてください。

最初からやり直すには、**「フレンドリー」の指示に戻す** をタップします。フレンドリーペルソナの指示が入力欄に入るので、それを出発点にできます。

## ペルソナで変わらないもの

ペルソナが変えるのはアシスタントへの指示だけです。モデル、返信の長さ、創造性（温度）など、[設定](07-settings.md)の他の項目は変わりません。
