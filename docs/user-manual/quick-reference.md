# Quick reference card

[← Manual home](README.md)

Everything on one page. Print it or keep it open in a tab.

## Buttons

| Button | Where | What it does |
|---|---|---|
| **☰** | Header, left | Show or hide the chat list |
| **+** | Header, right | Start a new chat |
| **⚙** | Header, right | Open Settings |
| Persona menu | Toolbar | Change the persona for this chat |
| Model menu | Toolbar | Choose or switch the AI model |
| **Clear** | Toolbar | Delete the chat that's open (asks first) |
| **Attach** | Toolbar | Add a PDF, TXT or Markdown file to this chat |
| **Send** (paper plane) | Next to the message box | Send your message |
| **Stop** (red square) | Replaces Send while a reply is written | Stop the reply and keep what's written so far |
| **Copy** | Under a reply | Copy the reply |
| **Regenerate** / **Retry** | Under the last reply | Write the last reply again / try again after an error |
| **Continue** | Under a cut-off reply | Finish the reply |
| **Jump to latest** / **Follow the reply** | Above the toolbar, after scrolling up | Go back to the bottom of the chat |
| 🗑 | Each chat in the chat list | Delete that chat (asks first) |
| **×** on a document chip | Above the message box | Remove that document from this chat |
| **Thought process** | Above a reply from a thinking model | Show or hide the model's reasoning |

On phones, **Clear** and **Attach** show only their icons.

## Common tasks

| I want to… | Do this |
|---|---|
| Ask a question | Type in the message box, press **Enter** or tap **Send** |
| Start fresh | Tap **+** |
| Find an old chat | **☰** → type in **Search chats** |
| Get shorter, factual answers | Persona menu → **🎯 Precise** |
| Get help writing | Persona menu → **✍️ Writer** |
| Ask about a file | **Attach** → choose the file → ask your question |
| Get faster replies | Choose a smaller model, or tap the suggestion in the speed hint |
| Get better answers | Choose a bigger model (**Settings → Help me choose a model** → Smart) |
| Allow longer replies | **Settings → Replies → Max Tokens** |
| Fix gibberish replies | Tap **Switch model** in the warning, or pick a **32-bit** model |
| Change the app's language | **Settings → Language** |
| Back up my chats | **Settings → Export Chats** |
| Move chats to another device | Export Chats here → **Import Chats** there |
| Install the app | **Settings → This device → Install app** (iPhone/iPad: Safari **Share → Add to Home Screen**) |

## Remember

* 🔒 Everything stays on your device. Nothing you type is sent anywhere.
* 💾 Chats save automatically, but only in this browser. Export them to back them up.
* ✈️ Works offline with models you've downloaded (✓).
* ⚠️ AI can make mistakes. Double-check important facts.
