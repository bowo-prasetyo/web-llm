# 3. チャットの管理

[← チャットする](02-chatting.md) · [マニュアルのトップ](README.md) · [次へ: ペルソナ →](04-personas.md)

すべての会話は、それぞれ別の*チャット*として自動で保存されます。この章では、チャットの開始、検索、再表示、削除の方法を説明します。

## チャット一覧

チャット一覧には、保存されたすべてのチャットが表示されます。各項目には、チャットのタイトル（最初のメッセージから自動で作られます）、短いプレビュー、使ったモデル、ペルソナのアイコン、最後に使った日時が表示されます。

**広い画面（パソコン）:** 一覧は会話の左側に表示されます。

* 隠すには、ヘッダーの **☰** か、一覧上部の **×** をタップします。もう一度 **☰** をタップすると表示されます。
* 表示・非表示の状態はアプリが覚えています。

**狭い画面（スマートフォン、小さいウィンドウ）:** 一覧は会話の上にスライドして表示されます。

* **☰**（チャット履歴）をタップして開きます。
* **×** をタップする、一覧の外側をタップする、または **Escape** キーを押すと閉じます。

## 新しいチャットを始める

ヘッダーの **+**（新しいチャット）をタップします。

現在のチャットが先に保存され、新しいウェルカム画面が表示されます。ペルソナを選んで入力を始められます。

> **ヒント:** 話題を変えるときは、新しいチャットを始めましょう。関係のない以前の会話に気を取られないほうが、アシスタントは良い回答をします。チャット一覧も検索しやすくなります。

## チャットを再び開く

チャット一覧を開き、チャットをタップします。メッセージ、ペルソナ、添付したドキュメントがすべて戻り、アシスタントも会話を覚えているので、続きから話せます。

## チャットを検索する

1. チャット一覧を開きます。
2. 上部の **チャットを検索** 欄に入力します。

検索は、プレビューだけでなく、チャットのタイトル、あなたの質問、アシスタントの回答の**すべて**が対象です。

* 結果には一致した部分が強調表示されるので、なぜそのチャットが見つかったのかがわかります。
* 一致度の高いものが先に表示されます。
* 結果をタップすると、そのチャットが開きます。
* 検索欄の **×** をタップすると検索をクリアします。

## チャットを削除する

方法は3つあります。どの方法でも**削除の前に確認**するので、うっかり削除してしまうことはありません。

| 場所 | 方法 |
|---|---|
| チャット一覧 | チャットにマウスを重ねる（タッチ画面では常に表示）と出る 🗑 ゴミ箱アイコンをタップします。 |
| ツールバー | **削除** をタップすると、開いているチャットを削除します。 |
| 設定 | **設定 → 現在のチャット → 会話を削除** で、開いているチャットを削除します。 |

**このチャットを削除しますか？** というダイアログが表示されます。**チャットを削除** で確定、**キャンセル** で残します。

> **重要:** チャットを削除すると、メッセージ*と*添付したドキュメントがこのブラウザから削除されます。**元に戻すことはできません。** 先にコピーを残すには、**設定 → チャットをエクスポート** を使ってください（[データのバックアップと移行](08-offline-and-backup.md#データのバックアップと移行)を参照）。

## 自動保存と復元

「保存」ボタンを押す必要はありません。

* 送信したメッセージと返信は、表示された時点ですぐに保存されます。
* タブを閉じても、ページを再読み込みしても、スマートフォンの画面が消えても、戻ってきたときにチャットは残っています。
* **アシスタントが答えている途中で**タブを閉じた場合は、次にアプリを開いたときに、同じ質問が自動でもう一度送られます。

## チャットはいくつ保存できる？

ブラウザのストレージが許す限り保存できます。アプリが勝手にチャットを削除することはありません。

> **メモ:** 一部のプライベート（シークレット）ブラウズでは、アプリが使えるストレージが限られます。40メッセージのチャットを50件までで、プライベートウィンドウを閉じると消える場合があります。どのストレージを使っているかは **設定 → このデバイス → チャットの保存先** で確認できます。
