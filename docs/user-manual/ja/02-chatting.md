# 2. アシスタントとチャットする

[← はじめに](01-getting-started.md) · [マニュアルのトップ](README.md) · [次へ: チャットの管理 →](03-managing-chats.md)

この章では、毎日使う操作を説明します。

## メッセージを送る

1. 画面下部のメッセージ欄（*何でも聞いてください…* と表示されています）をクリックまたはタップします。
2. 質問や依頼を入力します。
3. 送信します。
   * **パソコン:** **Enter** を押します。
   * **スマートフォン・タブレット:** **送信** ボタン（紙飛行機のアイコン）をタップします。
   * **どこでも:** **Ctrl+Enter**（Windows、Linux）または **Cmd+Enter**（Mac）でも送信できます。

### 送信せずに改行する

* **パソコン:** **Shift+Enter** を押します。
* **スマートフォン・タブレット:** 画面キーボードの **Enter** を押します。（タッチ画面ではEnterは改行になり、送信は送信ボタンだけで行います。）

メッセージ欄は入力に合わせて広がるので、メッセージ全体を確認できます。

> **メモ:** 日本語入力（IME）で変換を確定するためにEnterを押しても、メッセージが誤って送信されることはありません。

## 返信が表示されるのを見る

返信は、AIが書くのに合わせて少しずつ表示されます。書いている間は次のようになります。

* **送信** ボタンが、赤く点滅する **停止** ボタンに変わります。
* **上にスクロール**して前のメッセージを読み返せます。画面はその位置にとどまります。
* **返信を追う** ボタンが表示されます。タップすると下に戻り、新しい文章を追いかけます。（何も書かれていないときは、同じボタンが **最新へ移動** になります。）

> **速さはどのくらい？** 何回か返信すると、ツールバーの上に、現在のモデルがこのデバイスでどのくらいの速さで書くかが表示されます。例: *「Qwen3.5 2Bはこのデバイスで約6語/秒の速さで書きます。」* 遅い場合は、1回のタップで切り替えられる小さいモデルが提案されます。[モデルを選ぶ](06-models.md)をご覧ください。

## 返信を止める

赤い **停止** ボタンをいつでもタップできます。それまでに書かれた部分は残り、保存されます。

回答が見当違いの方向に進んでいるときや、必要以上に長いときに便利です。

## 返信のツール

書き終わった返信の下には、次のボタンがあります。

| ボタン | 動作 |
|---|---|
| **コピー** | 返信全体をクリップボードにコピーします。ボタンに一瞬 **コピーしました** と表示されます。 |
| **再生成** | *（最後の返信のみ）* 最後のメッセージにもう一度答えてもらいます。たいてい別の回答になります。 |
| **再試行** | *（エラーの後、再生成の代わりに表示）* 最後のリクエストをもう一度試します。 |
| **続ける** | *（返信が途中で打ち切られたときのみ）* 止まったところから続きを書きます。 |

### 返信が途中で打ち切られたのはなぜ？

返信の最後にメモが付くことがあります。それぞれの意味は次のとおりです。

| メモ | 意味 | 対処 |
|---|---|---|
| *最大トークン数（…）で打ち切りました。* | 返信が設定の最大の長さに達しました。 | **続ける** で続きを書かせるか、[設定](07-settings.md#最大トークン数)で **最大トークン数** を増やします。 |
| *停止: モデルが1分間書かなくなりました。* | モデルが行き詰まり、先に進まなくなりました。 | **続ける** または **再生成** をタップします。何度も起きる場合は、小さいモデルを試してください。 |
| *1回の返信の上限である20分で打ち切りました。* | とても長い返信に対する安全のための上限です。 | **続ける** をタップします。 |
| *返信が同じことを繰り返し始めたため、そこで止めました。* | モデルが同じ文を繰り返し始めました。繰り返し部分は削除されています。 | 続けて質問するか、**再生成** します。 |

## 返信の書式

返信は読みやすいように、見出し、箇条書き、番号付きの手順、表、リンクで整えられます。リンクは新しいタブで開きます。

**コード**は、プログラミング言語名が表示された網掛けのボックスに入り、専用の **コピー** ボタンでコードだけをコピーできます。色分け（シンタックスハイライト）は返信が終わってから付きます。

あなた自身のメッセージは、入力したとおりにそのまま表示されます。

## 「考える」モデル

一部のモデル（Qwen3、Qwen3.5、DeepSeek-R1）は、答える前に段階的に推論できます。

* モデルが考えている間は、**考えています…** とそのメモが表示されます。
* 終わると、メモは **思考過程** の下に折りたたまれます。タップすると読めます。
* 返信をコピーするとき、このメモは含まれません。

Qwen3とQwen3.5では、遅くなり返信の長さも消費するため、考える機能は既定で **オフ** です。難しい質問で使いたい場合は、**設定 → 返信 → 推論モデルに先に考えさせる** でオンにしてください。DeepSeek-R1は常に考えます。

## アシスタントは会話を覚えている？

はい、同じチャットの中では覚えています。各チャットは前の発言を覚えているので、*「もっと短くして」* や *「2つ目のポイントを説明して」* のように続けて質問できます。

別々のチャットは記憶を共有しません。とても長いチャットは、やがてモデルが一度に「見る」ことのできる量（*コンテキストウィンドウ*）を超えます。そうなると、最も古いメッセージは自動的にモデルの読む範囲から外れます。ただし、画面には残ります。モデルの記憶を増やしたい場合は、[コンテキストウィンドウ](07-settings.md#コンテキストウィンドウ)をご覧ください。

## より良い回答を得るコツ

* **具体的に頼む。** *「給湯器を直してくれた大家さんへのお礼メールを3文で書いて」* のほうが、*「メールを書いて」* より良い結果になります。
* **形式を指定する。** *「表で答えて」*、*「箇条書きで5つ」*、*「200字以内で」* など。
* **続けて頼む。** 回答が少し違うときは、最初からやり直すより、どこを直すかを伝えましょう。
* **合ったペルソナを選ぶ。** 短い事実なら **的確**、文章なら **ライター**、コードなら **コーダー**。[ペルソナ](04-personas.md)をご覧ください。
* **大切な事実は確認する。** デバイス上で動く小さいモデルは、大きなオンラインサービスより知識が少なく、自信を持って間違えることがあります。
* **日本語について。** AIはあなたが書いた言語で返信します。小さいモデルは英語が最も得意です。日本語の回答がいまひとつなら、大きいモデル（Qwen3.5 2B以上）を試してください。
