# 8. オフラインでの利用、インストール、データの移行

[← 設定](07-settings.md) · [マニュアルのトップ](README.md) · [次へ: トラブルシューティング →](09-troubleshooting.md)

> この章のブラウザのメニュー名は、ブラウザの表示言語によって変わります。日本語の表示が異なる場合のために、英語の名前もかっこ内に記載しています。

## アプリをオフラインで使う

一度オンラインのときにアプリを開けば、その後は**インターネット接続なしで**使えます。

**オフラインでできること:**

* アプリを開く
* ダウンロード済みのモデル（モデルメニューで ✓ の付いたもの）でチャットする
* 保存したチャットを読む、検索する、削除する
* ドキュメントを添付する（大きいドキュメントは、オンラインのときに一度大きいドキュメントを添付して、検索用ツールが保存されていれば可能）

**接続が必要なこと:**

* まだ持っていないモデルのダウンロード
* **初めて**添付する大きいドキュメント（小さな23 MBの検索用ツールを1回だけダウンロードします）

オフラインのときは、ステータスバーに **オフライン** と表示されます。ダウンロードしていないモデルを選ぶと、接続が必要だと説明されます。

オフラインで使う準備ができているかは、**設定 → このデバイス → オフラインで動作** で確認できます。*「はい、アプリはこのデバイスに保存されています」* と表示されていれば大丈夫です。

> **ヒント:** 飛行機に乗る前や旅行の前に、オンラインのときに一度アプリを開き、お気に入りのモデルに ✓ が付いていることを確認しましょう。

## アプリをインストールする

Hearthをインストールすると、普通のアプリのように専用のウィンドウで開き、デスクトップ、Dock、ホーム画面にアイコンが置かれます。

### ChromeまたはEdge（Windows、Mac、Linux、Android）

1. **設定 → このデバイス** を開きます。
2. **アプリをインストール** をタップして確定します。

ボタンが表示されない場合は、ブラウザのメニューで **Hearthをインストール**（*Install Hearth*）または **ホーム画面に追加**（*Add to Home screen*）を探してください。パソコンのChromeやEdgeでは、アドレスバーにインストールのアイコンが表示されることもあります。

### iPhoneまたはiPadのSafari

1. **Safari** でアプリを開きます。
2. **共有** ボタン（*Share*: 矢印の付いた四角）をタップします。
3. **ホーム画面に追加**（*Add to Home Screen*）をタップし、**追加**（*Add*）をタップします。

### MacのSafari

Safariで **ファイル → Dockに追加**（*File → Add to Dock*）を選びます。

インストールしたアプリは、ブラウザ版と同じチャット、設定、モデルを使います。

## アプリの更新

オンラインのときは更新が自動で届きます。何もする必要はありません。

新しいバージョンが出たときにタブを開いたままにしていると、**「アプリの新しいバージョンがあります。」** というバーが表示されます。

* **再読み込み** をタップすると、すぐに更新します。返信を書いている途中の場合は、ボタンが **この返信の後で再読み込み** になり、書き終わるのを待ちます。
* **×** をタップすると閉じて、あとで更新できます。

アプリを更新しても、チャットと設定はそのまま残ります。

## データのバックアップと移行

チャットは**このデバイスのこのブラウザの中**だけにあります。自動では同期されません。バックアップや、別のブラウザ、パソコン、スマートフォンへの移行には、エクスポートとインポートを使います。

### チャットをバックアップする

1. **設定 → エクスポート / インポート** を開きます。
2. **💬 チャット履歴** の下の **チャットをエクスポート** をタップします。
3. `hearth-chats-2026-11-04.json` のような名前のファイルがダウンロードされます。安全な場所に保管してください。

このファイルには、すべてのチャット、メッセージ、添付したドキュメントが含まれます。

> **重要:** エクスポートしたファイルには、アプリで書いたすべての内容が読める形で含まれます。日記と同じように、慎重に保管・共有してください。

### 設定をバックアップする

**⚙ 設定** の下の **設定をエクスポート** をタップします。`hearth-settings-2026-11-04.json` のような名前のファイルがダウンロードされます。

### 別のデバイスやブラウザに移す

1. **元の**デバイスで、上の手順でチャット（必要なら設定も）をエクスポートします。
2. ファイルを**新しい**デバイスにコピーします（自分宛てのメール、USBメモリ、クラウドストレージなど）。
3. 新しいデバイスでアプリを開き、**設定 → エクスポート / インポート** に進みます。
4. **チャットをインポート** をタップしてチャットのファイルを、**設定をインポート** をタップして設定のファイルを選びます。

**インポートについて:**

* インポートしたチャットは、デバイスに既にあるチャットに**追加**されます。上書きされるものはありません。
* 既にあるチャットは認識されてスキップされるので、同じファイルを2回インポートしても重複しません。
* 設定をインポートしても、新しいデバイスで既に選ばれているモデルはそのままなので、思わぬダウンロードは始まりません。あとでいつもどおりモデルを選んでください。
* **外観** と **言語** の選択はエクスポートに含まれません。必要なら新しいデバイスで設定し直してください。

> **メモ:** モデルはエクスポートに**含まれません**（数GBあるためです）。新しいデバイスでは、初回にモデルをダウンロードします。

## データの保存場所

すべて、このデバイスのブラウザのストレージに保存されます。

* チャットと添付したドキュメント
* 設定とペルソナ
* ダウンロードしたAIモデル
* オフライン用のアプリ本体のコピー

ブラウザの設定で**このサイトのデータを消去**すると、これらはすべて削除されます。チャットを残したい場合は、先にエクスポートしてください。
