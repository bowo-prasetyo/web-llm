# 6. モデルを選ぶ

[← ドキュメント](05-documents.md) · [マニュアルのトップ](README.md) · [次へ: 設定 →](07-settings.md)

**モデル**は返信を書くAIです。Hearthには、スマートフォンで動く極小のものから、強力なグラフィックスカードが必要な大きいものまで、55のオープンなモデルがあります。この章では、合ったモデルの選び方と切り替え方を説明します。

## 要点

* **迷ったらモデル選択を使う。** **設定 → モデル選びを手伝って**（またはウェルカム画面の **モデル選びを手伝って**）を開き、2つの質問に答えると、デバイスに合ったモデルが選ばれます。
* **返信が遅すぎる？** 小さいモデルを選びます。
* **回答が物足りない？** デバイスが対応できるなら、大きいモデルを選びます。
* **モデルを切り替えてもチャットは消えません。** 新しいモデルが会話の続きを担当します。

## 大きいモデルと小さいモデル

モデルの大きさは**パラメータ**の数で表され、*0.8B* や *9B* のように書きます（B = 10億）。パラメータが多いほど一般に賢くなりますが、ダウンロードが大きくなり、返信も遅くなります。

| サイズ | ダウンロード | 必要なGPUメモリ | 速さ | 回答の質 | 動く環境 |
|---|---|---|---|---|---|
| 極小（1B未満） | 約0.2〜0.7 GB | 約0.6〜1.9 GB | 最速 | 基本的。事実を間違えることがあります | 多くのスマートフォン、古いノートPC |
| 小（1〜2B） | 約0.5〜1.4 GB | 約0.7〜2.6 GB | 速い | 日常の用途に十分 | 多くのノートPC、メモリの多いスマートフォン |
| 中（3〜4B） | 約1.6〜2.3 GB | 約2.2〜5.4 GB | 中程度 | はっきり良くなる | 良いGPUを積んだノートPC |
| 大（7〜9B） | 約3.8〜4.9 GB | 約4.8〜7.4 GB | 遅め | ここで使える中で最高 | 専用グラフィックスカード（ビデオメモリ6 GB以上）のパソコン |

モデルは動いている間、ダウンロードサイズより多くのGPUメモリを使います。最小のモデルでは約4倍にもなります。モデルがデバイスで動くかどうかを決めるのは、ダウンロードの大きさではなくメモリです。

## スマートフォン

スマートフォンがAIに使わせるメモリは、パソコンよりずっと少なくなります。スマートフォンに大きすぎるモデルはエラーを表示せず、スマートフォンがそのままページを閉じます。もう一度開くと、アプリが何が起きたかを説明し、そのモデルは再度読み込まずに小さいモデルを提案するので、1段階ずつサイズを下げられます。停止したモデルは、モデルメニューに **⚠ このデバイスで停止しました** と表示されます。

どこまで下げる必要があるかは機種によります。テストしたあるAndroidスマートフォンでは、Qwen3.5 0.8B、Llama 3.2 1B、Gemma 3 1B、TinyLlamaはすべてページが閉じ、収まったのはSmolLM2 360M（約0.6 GB）だけでした。この大きさの極小モデルはほとんど会話になりません。実用にはパソコンのほうがはるかに向いています。

## おすすめ

| こんなときは… | 試すモデル |
|---|---|
| いちばん軽いもの | Gemma 3 1B または Qwen3.5 0.8B |
| スマートフォン向け | メモリが十分ならLlama 3.2 1BまたはGemma 3 1B、そうでなければSmolLM2 360M（[スマートフォン](#スマートフォン)を参照） |
| 日常のチャット | Qwen3.5 2B、性能の高いデバイスならQwen3.5 4B |
| プログラミングの手助け | Qwen3.5 4B または Qwen3.5 9B |
| 文章作成の手助け | Qwen3.5 4B または Ministral 3 3B |
| 段階的な推論 | **推論モデルに先に考えさせる** をオンにしたQwen3.5、または DeepSeek-R1 Distill Qwen 7B |
| 英語以外の言語（日本語を含む） | Qwen3.5 2B または Qwen3.5 4B |
| 指示に忠実に従う | Phi-4-mini |
| 最も高性能 | Qwen3.5 9B（強力なGPUが必要） |

## モデル選択を使う

1. **設定 → モデル選びを手伝って**、またはウェルカム画面から開きます。
2. 主な用途を選びます: **日常のチャット**、**プログラミング**、**文章作成**。
3. サイズを選びます: **高速**、**バランス**、**高性能**。
   * **おすすめ** は、お使いのデバイスに最も合うものです。
   * **使用中** は、今使っているモデルです。
   * **ダウンロード済み** なら、ダウンロードは不要です。
4. **ダウンロードして開始**（ダウンロード済みなら **開始**）をタップします。

## 一覧からモデルを選ぶ

**モデルメニュー**はツールバー（と **設定 → モデル**）にあります。モデルはサイズ別に、軽いものから重いものの順に並んでいます。

各項目は次のように表示されます。

> **Qwen3.5 2B · 16-bit · 1010 MB ✓**

| 部分 | 意味 |
|---|---|
| Qwen3.5 2B | モデルの名前と大きさ |
| 16-bit / 32-bit | モデルがGPUで使う演算の種類（下記参照） |
| 1010 MB | ダウンロードサイズ |
| ✓ | このデバイスにダウンロード済み |
| ⚠ | このデバイスでは正しく動かない可能性（下記参照） |

### 新しいモデルをダウンロードする

初めてモデルを選ぶと、**モデルをダウンロードしますか？** というダイアログにサイズが表示されます。**ダウンロードして読み込む** で続行、**キャンセル** で今のモデルのままにします。

ダウンロード中は、進行状況パネルの **キャンセル** をタップできます。アプリは前のモデルと設定に戻ります。

> **メモ:** 新しいモデルのダウンロードにはインターネット接続が必要です。オフラインのときは、ダウンロードを試みる代わりにその旨を説明します。

### チャットの途中でモデルを切り替える

いつでも切り替えられます。現在の会話は画面に残り、新しいモデルがそこから続けます。新しいモデルのおすすめ返信設定が自動で適用されます。

## 16ビットモデルと32ビットモデル

多くのモデルには2つの版があります。

* **16ビット（q4f16）**: 小さくて速い。通常はこちらがおすすめです。
* **32ビット（q4f32）**: 少し大きく遅いですが、より多くのデバイスで動きます。

一部のグラフィックスチップは16ビット演算を正しく行えません。その場合、16ビットモデルは意味不明な文字列（例: *"outer outer outer…"*）を返します。

**アプリはこれを自動でチェックします。** 各モデルがお使いのデバイスで初めて読み込まれたときに、短いテストを行います。モデルがテストに失敗すると、**このモデルはお使いのGPUでは動きません** というダイアログで、動作する32ビット版が提案されます。

* **モデルを切り替える** — 提案された32ビットモデルを使います（おすすめ）。
* **このモデルを使い続ける** — 今のモデルをそのまま使います。

16ビットが正しく動かないデバイスでは、モデル一覧の16ビットモデルに ⚠ が付き、モデル選択でも自動的に32ビット版が提案されます。

## 速さの表示

モデルが何回か返信すると、ツールバーの上に、そのモデルがこのデバイスでどのくらいの速さで書くかが表示されます。例:

> *Qwen3.5 4Bはこのデバイスで約2語/秒の速さで書きます。もっと速く返信がほしい場合は**Qwen3.5 2B**を試してください（速いですが、間違いが増えます）。*

提案されたモデル名をタップすると、そのモデルに切り替わります。日本語のように単語の間にスペースのない言語でも、単語は正しく数えられます。

## ストレージを空ける

ダウンロードしたモデルは、次回すぐに読み込めるようブラウザに保存されます。大きいモデルは数GBになることもあります。削除するには、ブラウザの設定でこのサイトのデータを消去します。

> **重要:** サイトのデータを消去すると、ダウンロードしたモデル、チャット、ドキュメント、設定の**すべて**が削除されます。チャットを残したい場合は、先にエクスポートしてください（[データのバックアップと移行](08-offline-and-backup.md#データのバックアップと移行)を参照）。
