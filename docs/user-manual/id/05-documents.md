# 5. Bertanya tentang dokumen Anda

[← Persona](04-personas.md) · [Beranda panduan](README.md) · [Berikutnya: Memilih model →](06-models.md)

Anda bisa melampirkan dokumen ke sebuah chat dan bertanya tentang isinya, seperti *"Rangkum laporan ini"* atau *"Apa kata kontrak ini tentang pembatalan?"* File dibaca di dalam browser Anda dan **tidak pernah meninggalkan perangkat Anda**.

## File yang didukung

| Jenis | Ekstensi |
|---|---|
| PDF | `.pdf` (harus berisi teks sungguhan, lihat di bawah) |
| Teks biasa | `.txt` |
| Markdown | `.md`, `.markdown` |

**Batas:**

* Ukuran file: sampai **50 MB** secara bawaan. Anda bisa menaikkannya sampai 200 MB di **Setelan → Dokumen → Ukuran Unggahan Maksimum**.
* Panjang teks: sampai sekitar **500.000 karakter (kira-kira 200 halaman)** per dokumen.

> **Catatan:** PDF hasil pindaian (foto halaman) tidak punya lapisan teks, jadi aplikasi tidak bisa membacanya. Jika Anda tidak bisa memilih teks di PDF itu dengan mouse, kemungkinan besar itu hasil pindaian.

## Melampirkan dokumen

1. Buka chat yang ingin Anda pakai (atau mulai chat baru).
2. Ketuk **Lampirkan** (ikon penjepit kertas) di bilah alat.
3. Pilih file Anda.

File muncul sebagai **cip** di atas kotak pesan dengan nama, ukuran, dan status saat file sedang dibaca atau disiapkan. Saat statusnya tidak berubah lagi, file siap dipakai.

Anda bisa melampirkan lebih dari satu dokumen ke chat yang sama.

## Bertanya tentang dokumen

Ketik pertanyaan Anda seperti biasa. Contoh:

* *"Rangkum dokumen ini dalam lima poin."*
* *"Apa ketentuan pembayarannya?"*
* *"Sebutkan setiap tanggal yang disebut dan apa yang terjadi pada tanggal itu."*
* *"Jelaskan bagian 3 dengan bahasa sederhana."*

Aplikasi otomatis memberikan bagian dokumen yang relevan kepada asisten bersama setiap pertanyaan.

## Cara kerjanya (dengan bahasa sederhana)

* **Dokumen pendek** diberikan kepada asisten **secara utuh** bersama setiap pertanyaan.
* **Dokumen panjang** terlalu besar untuk diberikan sekaligus. Sebagai gantinya, aplikasi memecahnya menjadi potongan kecil dan, untuk setiap pertanyaan, memilih potongan yang paling cocok dengan pertanyaan Anda. Saat pertama kali Anda melampirkan dokumen panjang, aplikasi mengunduh alat bantu pencarian kecil (sekitar 23 MB, hanya sekali).
* **Permintaan umum** seperti *"rangkum ini"* tidak cocok dengan satu bagian tertentu, jadi asisten mendapat bagian awal setiap dokumen.

> **Tips:** Untuk dokumen panjang, pertanyaan yang spesifik paling berhasil. *"Apa isinya tentang pengembalian dana?"* lebih andal menemukan bagian yang tepat daripada *"Ceritakan semuanya."* Untuk ringkasan menyeluruh dari file yang sangat panjang, tanyakan satu bagian dalam satu waktu.

> **Bahasa:** Alat bantu pencarian bekerja paling baik untuk teks berbahasa Inggris. Untuk dokumen berbahasa Indonesia, pemilihan bagian bisa kurang tepat; sebutkan kata-kata yang memang ada di dokumen agar bagian yang benar lebih mudah ditemukan.

## Lampiran milik satu chat

* Dokumen yang dilampirkan ke satu chat **hanya** dipakai di chat itu. Chat lain tidak bisa melihatnya.
* Dokumen disimpan bersama chat, jadi masih ada saat Anda membuka chat itu lagi nanti.
* Dokumen ikut dihapus, diekspor, dan diimpor bersama chat-nya.
* Chat yang hanya berisi dokumen dan belum ada pesannya tetap disimpan di daftar Anda, berjudul 📎 dan nama file.

## Menghapus dokumen

Ketuk **×** pada cip dokumen. Dokumen dihapus dari chat ini saja.

## Dokumen dari versi lama

Jika Anda pernah memakai versi aplikasi yang lebih lama, Anda mungkin melihat catatan bahwa dokumen yang Anda tambahkan sebelumnya *"dulu dipakai bersama oleh semua chat dan kini tidak digunakan lagi."* Lampirkan file yang Anda perlukan ke masing-masing chat, lalu ketuk **Hapus dokumen itu** untuk membersihkan salinan lama.

## Privasi

File yang dilampirkan dibaca dan dicari sepenuhnya di perangkat Anda. File disimpan di browser Anda bersama chat-nya dan tidak pernah diunggah ke mana pun.
