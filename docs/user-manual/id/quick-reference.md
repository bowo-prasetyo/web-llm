# Kartu referensi cepat

[← Beranda panduan](README.md)

Semuanya dalam satu halaman. Cetak atau biarkan terbuka di sebuah tab.

## Tombol

| Tombol | Di mana | Fungsinya |
|---|---|---|
| **☰** | Kepala halaman, kiri | Menampilkan atau menyembunyikan daftar chat |
| **+** | Kepala halaman, kanan | Memulai chat baru |
| **⚙** | Kepala halaman, kanan | Membuka Setelan |
| Menu persona | Bilah alat | Mengganti persona untuk chat ini |
| Menu model | Bilah alat | Memilih atau mengganti model AI |
| **Hapus** (tempat sampah) | Bilah alat | Menghapus chat yang sedang terbuka (bertanya dulu) |
| **Lampirkan** (penjepit kertas) | Bilah alat | Menambahkan file PDF, TXT, atau Markdown ke chat ini |
| **Kirim** (pesawat kertas) | Di samping kotak pesan | Mengirim pesan Anda |
| **Hentikan** (kotak merah) | Menggantikan Kirim selama balasan ditulis | Menghentikan balasan dan menyimpan yang sudah ditulis |
| **Salin** | Di bawah balasan | Menyalin balasan |
| **Buat ulang** / **Coba lagi** | Di bawah balasan terakhir | Menulis ulang balasan terakhir / mencoba lagi setelah kesalahan |
| **Lanjutkan** | Di bawah balasan yang terpotong | Menyelesaikan balasan |
| **Ke pesan terbaru** / **Ikuti balasan** | Di atas bilah alat, setelah menggulir ke atas | Kembali ke bagian bawah chat |
| 🗑 | Setiap chat di daftar chat | Menghapus chat itu (bertanya dulu) |
| **×** pada cip dokumen | Di atas kotak pesan | Menghapus dokumen itu dari chat ini |
| **Proses berpikir** | Di atas balasan dari model yang berpikir | Menampilkan atau menyembunyikan penalaran model |

Di ponsel, **Hapus** dan **Lampirkan** hanya menampilkan ikonnya.

## Tugas umum

| Saya ingin… | Lakukan ini |
|---|---|
| Bertanya | Ketik di kotak pesan, tekan **Enter** atau ketuk **Kirim** |
| Mulai dari awal | Ketuk **+** |
| Menemukan chat lama | **☰** → ketik di **Cari chat** |
| Mendapat jawaban singkat dan faktual | Menu persona → **🎯 Presisi** |
| Mendapat bantuan menulis | Menu persona → **✍️ Penulis** |
| Bertanya tentang file | **Lampirkan** → pilih file → ajukan pertanyaan |
| Mendapat balasan lebih cepat | Pilih model yang lebih kecil, atau ketuk saran di petunjuk kecepatan |
| Mendapat jawaban lebih baik | Pilih model yang lebih besar (**Setelan → Bantu saya memilih model** → Pintar) |
| Mengizinkan balasan lebih panjang | **Setelan → Balasan → Token Maksimum** |
| Mengatasi balasan kacau | Ketuk **Ganti model** di peringatan, atau pilih model **32-bit** |
| Mengganti bahasa aplikasi | **Setelan → Bahasa** |
| Mencadangkan chat | **Setelan → Ekspor Chat** |
| Memindahkan chat ke perangkat lain | Ekspor Chat di sini → **Impor Chat** di sana |
| Memasang aplikasi | **Setelan → Perangkat ini → Pasang aplikasi** (iPhone/iPad: Safari **Bagikan → Tambah ke Layar Utama**) |

## Ingat

* 🔒 Semuanya tetap di perangkat Anda. Tidak ada yang Anda ketik yang dikirim ke mana pun.
* 💾 Chat tersimpan otomatis, tetapi hanya di browser ini. Ekspor untuk mencadangkannya.
* ✈️ Bisa dipakai offline dengan model yang sudah Anda unduh (✓).
* ⚠️ AI bisa keliru. Periksa lagi fakta yang penting.
