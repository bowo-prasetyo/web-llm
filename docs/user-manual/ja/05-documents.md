# 5. ドキュメントについて質問する

[← ペルソナ](04-personas.md) · [マニュアルのトップ](README.md) · [次へ: モデルを選ぶ →](06-models.md)

チャットにドキュメントを添付して、*「このレポートを要約して」* や *「契約書には解約について何と書いてある？」* のように内容について質問できます。ファイルはブラウザの中で読み込まれ、**デバイスの外に出ることはありません**。

## 対応しているファイル

| 種類 | 拡張子 |
|---|---|
| PDF | `.pdf`（実際のテキストを含むもの。下記参照） |
| テキスト | `.txt` |
| Markdown | `.md`、`.markdown` |

**上限:**

* ファイルサイズ: 既定で **50 MB** まで。**設定 → ドキュメント → アップロードの最大サイズ** で200 MBまで上げられます。
* テキストの長さ: 1つのドキュメントにつき約 **500,000文字（およそ200ページ）** まで。

> **メモ:** スキャンしたPDF（ページを撮影したもの）にはテキストレイヤーがないため、アプリでは読めません。マウスでPDFの文字を選択できない場合は、スキャンしたものの可能性が高いです。

## ドキュメントを添付する

1. 使いたいチャットを開きます（または新しいチャットを始めます）。
2. ツールバーの **添付**（クリップのアイコン）をタップします。
3. ファイルを選びます。

ファイルはメッセージ欄の上に **チップ** として表示され、名前、サイズ、読み込み・準備中の状態が表示されます。状態の表示が落ち着いたら準備完了です。

同じチャットに複数のドキュメントを添付できます。

## 質問する

いつもどおり質問を入力するだけです。例:

* *「このドキュメントを5つの箇条書きで要約して。」*
* *「支払い条件は？」*
* *「出てくる日付と、その日に何があるかをすべて挙げて。」*
* *「第3節をわかりやすく説明して。」*

アプリは、質問のたびにドキュメントの関連部分を自動でアシスタントに渡します。

## しくみ（わかりやすく）

* **短いドキュメント**は、質問のたびに**全文**がアシスタントに渡されます。
* **長いドキュメント**は、一度に全部を渡すには大きすぎます。そこでアプリは小さな部分に分け、質問ごとに内容が最も合う部分を選びます。長いドキュメントを初めて添付したときは、小さな検索用ツール（約23 MB、1回だけ）をダウンロードします。
* *「要約して」* のような**全体的な依頼**は特定の部分に合わないため、各ドキュメントの冒頭部分が渡されます。

> **ヒント:** 長いドキュメントでは、具体的な質問が最も効果的です。*「返金について何と書いてある？」* のほうが、*「全部教えて」* より正しい部分を見つけやすくなります。とても長いファイル全体を要約したい場合は、1節ずつ質問してください。

> **日本語の文書について:** 検索用ツールは英語のテキストで最もよく機能します。日本語のドキュメントでは部分の選び方が不正確になることがあります。ドキュメントに実際に出てくる言葉を質問に入れると、正しい部分が見つかりやすくなります。

## 添付は1つのチャット専用

* あるチャットに添付したドキュメントは、そのチャット**だけ**で使われます。他のチャットからは見えません。
* チャットと一緒に保存されるので、あとでチャットを開いても残っています。
* チャットと一緒に削除、エクスポート、インポートされます。
* ドキュメントだけでまだメッセージのないチャットも、📎 とファイル名のタイトルで一覧に残ります。

## ドキュメントを外す

ドキュメントのチップの **×** をタップします。このチャットからだけ外れます。

## 以前のバージョンのドキュメント

以前のバージョンを使っていた場合、前に追加したドキュメントは *「すべてのチャットで共有されていたため、現在は使われていません」* というメモが表示されることがあります。必要なファイルを各チャットに添付し直してから、**削除する** をタップして古いコピーを消してください。

## プライバシー

添付したファイルの読み込みと検索は、すべてデバイス上で行われます。ファイルはチャットと一緒にブラウザに保存され、どこにもアップロードされません。
