# 8. Memakai secara offline, memasang aplikasi, dan memindahkan data

> Nama menu browser di bab ini tergantung bahasa browser Anda. Nama dalam bahasa Inggris ditulis dalam tanda kurung jika berbeda.

## Memakai aplikasi secara offline

Setelah Anda membuka aplikasi sekali saat online, aplikasi berfungsi **tanpa koneksi internet**.

**Berfungsi offline:**

* Membuka aplikasi
* Mengobrol dengan model apa pun yang sudah Anda unduh (bertanda ✓ di menu model)
* Membaca, mencari, dan menghapus chat yang tersimpan
* Melampirkan dokumen (untuk dokumen besar, setelah Anda pernah melampirkan satu dokumen besar saat online, sehingga alat bantu pencarian sudah tersimpan)

**Perlu koneksi:**

* Mengunduh model yang belum Anda miliki
* Dokumen besar **pertama** yang pernah Anda lampirkan (aplikasi mengunduh alat bantu pencarian kecil berukuran 23 MB, sekali saja)

Saat Anda offline, lencana **Offline** muncul di bilah status. Jika Anda memilih model yang belum diunduh, aplikasi menjelaskan bahwa model itu perlu koneksi.

Untuk memeriksa apakah aplikasi siap dipakai offline, buka **Setelan → Perangkat ini → Bisa offline**. Seharusnya tertulis *"Ya, aplikasi tersimpan di perangkat ini."*

> **Tips:** Sebelum naik pesawat atau bepergian, buka aplikasi sekali saat online dan pastikan model favorit Anda bertanda ✓.

## Memasang aplikasi

Anda bisa memasang Hearth agar terbuka di jendelanya sendiri, seperti aplikasi biasa, dengan ikon di desktop, dock, atau layar utama.

### Chrome atau Edge (Windows, Mac, Linux, Android)

1. Buka **Setelan → Perangkat ini**.
2. Ketuk **Pasang aplikasi** dan konfirmasi.

Jika tombolnya tidak muncul, gunakan menu browser Anda sendiri: cari **Instal Hearth** (*Install Hearth*) atau **Tambahkan ke Layar utama** (*Add to Home screen*). Di Chrome dan Edge di komputer, sering ada ikon pasang di bilah alamat.

### Safari di iPhone atau iPad

1. Buka aplikasi di **Safari**.
2. Ketuk tombol **Bagikan** (*Share*: kotak dengan panah).
3. Ketuk **Tambah ke Layar Utama** (*Add to Home Screen*), lalu **Tambah** (*Add*).

### Safari di Mac

Di Safari, pilih **File → Tambahkan ke Dock** (*File → Add to Dock*).

Aplikasi yang terpasang memakai chat, setelan, dan model yang sama dengan versi browser.

## Pembaruan aplikasi

Pembaruan datang otomatis saat Anda online; Anda tidak perlu melakukan apa pun.

Jika Anda membiarkan tab terbuka saat versi baru keluar, sebuah bilah bertuliskan **"Versi baru aplikasi tersedia."**

* Ketuk **Muat ulang** untuk memperbarui sekarang. Jika balasan sedang ditulis, tombolnya bertuliskan **Muat ulang setelah balasan ini** dan menunggu sampai selesai.
* Ketuk **×** untuk menutupnya dan memperbarui nanti.

Chat dan setelan Anda tetap ada saat aplikasi diperbarui.

## Mencadangkan dan memindahkan data Anda

Chat Anda hanya ada di **browser ini di perangkat ini**. Chat tidak tersinkron otomatis. Gunakan Ekspor dan Impor untuk membuat cadangan atau pindah ke browser, komputer, atau ponsel lain.

### Mencadangkan chat

1. Buka **Setelan → Ekspor / Impor**.
2. Di bawah **💬 Riwayat Chat**, ketuk **Ekspor Chat**.
3. File bernama seperti `hearth-chats-2026-11-04.json` akan diunduh. Simpan di tempat yang aman.

File ini berisi semua chat, pesan, dan dokumen terlampir Anda.

> **Penting:** File ekspor berisi semua yang Anda tulis di aplikasi, dalam bentuk yang bisa dibaca. Simpan dan bagikan dengan hati-hati, seperti buku harian pribadi.

### Mencadangkan setelan

Di bawah **⚙ Setelan**, ketuk **Ekspor Setelan**. File bernama seperti `hearth-settings-2026-11-04.json` akan diunduh.

### Pindah ke perangkat atau browser lain

1. Di perangkat **lama**, ekspor chat Anda (dan setelan, jika mau) seperti dijelaskan di atas.
2. Salin file tersebut ke perangkat **baru**, misalnya lewat email ke diri sendiri, flashdisk, atau penyimpanan cloud.
3. Di perangkat baru, buka aplikasi dan buka **Setelan → Ekspor / Impor**.
4. Ketuk **Impor Chat** dan pilih file chat. Ketuk **Impor Setelan** dan pilih file setelan.

**Tentang mengimpor:**

* Chat yang diimpor **ditambahkan** ke chat yang sudah ada di perangkat. Tidak ada yang tertimpa.
* Chat yang sudah ada dikenali dan dilewati, jadi mengimpor file yang sama dua kali tidak membuat duplikat.
* Mengimpor setelan tetap memakai model yang sudah dipilih di perangkat baru, jadi tidak pernah memicu unduhan yang tak terduga. Pilih model setelahnya seperti biasa.
* Pilihan **Tampilan** dan **Bahasa** tidak ikut diekspor; atur lagi di perangkat baru jika perlu.

> **Catatan:** Model **tidak** ikut diekspor (ukurannya beberapa gigabyte). Perangkat baru mengunduh modelnya sendiri saat pertama kali.

## Tempat data Anda disimpan

Semuanya tetap di penyimpanan browser Anda di perangkat ini:

* Chat dan dokumen terlampir
* Setelan dan persona
* Model AI yang sudah diunduh
* Salinan aplikasi itu sendiri, untuk dipakai offline

**Menghapus data situs ini** di setelan browser Anda menghapus semuanya. Ekspor lebih dulu jika Anda ingin menyimpan chat.
