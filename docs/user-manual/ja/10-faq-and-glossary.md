# 10. よくある質問と用語集

## よくある質問

### プライバシーとデータ

**本当にプライベートですか？**
はい。AIモデルはお使いのデバイスで動きます。メッセージ、チャット、ドキュメント、設定はブラウザの中だけに保存され、サーバーに送られることはありません。アカウントはなく、入力内容が追跡されることもありません。

**では、アプリは何をダウンロードするのですか？**
動くのに必要なものだけです。アプリ本体、AIモデルのファイル（Hugging FaceとGitHubから）、いくつかのコードライブラリ、フォント、そして大きいドキュメント用の小さな検索用ツールです。これらのリクエストに、入力した内容が含まれることはありません。

**他の人に私のチャットが見られますか？**
アプリを通じて見られることはありません。ただし、あなたのデバイスとブラウザを使える人は、閲覧履歴と同じように、アプリを開いてチャットを見ることができます。共有のパソコンでは自分用のブラウザプロファイルを使うか、使い終わったらチャットを削除してください。

**機密のドキュメントを添付しても安全ですか？**
ドキュメントはデバイス上でのみ読み込み・保存され、アップロードされることはありません。ただし、エクスポートしたチャットのファイルには添付したドキュメントも含まれるので、そのファイルは慎重に保管してください。

### 料金とアカウント

**料金はかかりますか？**
いいえ。サブスクリプションも、アカウントも、APIキーもありません。

**登録は必要ですか？**
いいえ。

### アプリの使い方

**スマートフォンで使えますか？**
動きますが、スマートフォンはAIに使えるメモリが少ないため、多くの機種では回答がごく限定的な極小モデルしか動きません。メモリの多いスマートフォンならLlama 3.2 1B（**高速** を選択）が動きます。モデルが大きすぎるとページが閉じ、次回は小さいモデルが提案されます。[スマートフォン](06-models.md#スマートフォン)をご覧ください。WebGPU対応のブラウザ（iOS 17以降のSafari、または最近のAndroid版Chrome）が必要です。最も良い回答を得るにはパソコンを使ってください。

**最初の起動が遅いのはなぜですか？**
初回はAIモデル（多くの場合0.4〜2 GB）をダウンロードするためです。その後は数秒でデバイスから読み込みます。

**インターネットなしで使えますか？**
はい。アプリとモデルをダウンロードした後なら使えます。[オフラインでの利用](08-offline-and-backup.md#アプリをオフラインで使う)をご覧ください。

**Webを検索したり、今日のニュースを知ったりできますか？**
いいえ。モデルが知っているのは、学習した内容と、あなたが入力または添付した内容だけです。インターネットを閲覧することはできず、最近の出来事を知らない場合があります。

**画像や音声を読めますか？**
いいえ。テキストと、テキストを含むPDF、TXT、Markdownのドキュメントに対応しています。

**複数のモデルを使えますか？**
はい。複数ダウンロードして、モデルメニューからいつでも（チャットの途中でも）切り替えられます。

**チャットを別のデバイスに移すには？**
**設定 → チャットをエクスポート** でエクスポートし、ファイルをコピーして、別のデバイスで **チャットをインポート** を使います。[データのバックアップと移行](08-offline-and-backup.md#データのバックアップと移行)をご覧ください。

**大きなオンラインAIアシスタントと同じくらい賢いですか？**
通常はそこまでではありません。個人のデバイスに収まるモデルはずっと小さいからです。日常の質問、文章作成の手助け、アイデア出し、簡単なコードには十分ですが、複雑な話題や専門的な話題では間違いが多くなります。その代わり、完全なプライバシーとオフラインでの利用が得られます。

**同じ質問でも答えが違うのはなぜですか？**
AIモデルにはある程度のランダムさがあります。**再生成** をタップすると別の答えが得られます。より安定した答えにしたい場合は、設定で **温度** を下げてください。

**日本語で使えますか？**
はい、2つの意味で使えます。アプリの表示を日本語にできます（**設定 → 言語**）。そしてAIは、あなたが書いた言語で返信します。日本語にはQwen3.5（2B以上）のモデルがおすすめです。極小モデルは日本語が不自然になりがちです。

## 用語集

| 用語 | 意味 |
|---|---|
| **AIモデル**（または**モデル**） | 返信を書く「頭脳」。モデルごとに大きさ、速さ、質が異なります。 |
| **添付ファイル** | 内容について質問するためにチャットに追加したドキュメント（PDF、TXT、Markdown）。 |
| **チャット**（または**セッション**） | 1つの会話。チャットはそれぞれチャット一覧に別々に保存されます。 |
| **コンテキストウィンドウ** | モデルが一度に「見る」ことのできるテキストの量。会話とドキュメントの抜粋が含まれます。この上限を超えた古いメッセージは読まれなくなります。 |
| **エクスポート / インポート** | バックアップや別のデバイスへの移行のために、チャットや設定をファイルに保存し、また読み込むこと。 |
| **GPU** | グラフィックス処理装置。デバイスの中で画像を描くチップです。アプリはこれを使ってAIを高速に動かします。 |
| **最大トークン数** | 1回の返信に許される最大の長さ。 |
| **パラメータ**（例: **2B**、**9B**） | モデルの大きさの指標。「2B」は20億パラメータです。大きいほど一般に賢いですが、遅くなります。 |
| **ペルソナ** | アシスタントのスタイル: フレンドリー、的確、ライター、コーダー、アイデア出し、または自分で書くカスタムの指示。 |
| **PWA / アプリをインストール** | Webアプリをインストールして、普通のアプリのように専用のウィンドウとアイコンで開けるようにすること。 |
| **q4f16 / q4f32**（16ビット / 32ビット） | 同じモデルの2つの版。16ビットは小さくて速く、32ビットはより多くのGPUで動きます。 |
| **再生成** | 最後の返信をAIにもう一度書いてもらうこと。 |
| **質問の例** | ウェルカム画面に表示される、最初のメッセージの例。タップすると送信されます。 |
| **温度** | 返信がどのくらい創造的（高い）か、予測しやすい（低い）か。 |
| **考える / 思考過程** | 一部のモデルが回答の前に書く、段階的な推論。読みたいときに開けるよう、折りたたんで表示されます。 |
| **トークン** | モデルが読み書きする単語の一部。100トークンは英語で約75語、日本語では100〜200文字ほどです。 |
| **WebGPU** | WebページからGPUを使えるようにするブラウザの機能。このアプリに必要です。 |
| **WebLLM** | WebブラウザでAIモデルを動かすオープンソースのエンジン。Hearthはこれを基盤にしています。 |
