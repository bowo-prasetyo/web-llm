# クイックリファレンス

[← マニュアルのトップ](README.md)

すべてを1ページにまとめました。印刷するか、タブで開いたままにしておくと便利です。

## ボタン

| ボタン | 場所 | 動作 |
|---|---|---|
| **☰** | ヘッダーの左 | チャット一覧を表示・非表示 |
| **+** | ヘッダーの右 | 新しいチャットを始める |
| **⚙** | ヘッダーの右 | 設定を開く |
| ペルソナメニュー | ツールバー | このチャットのペルソナを変える |
| モデルメニュー | ツールバー | AIモデルを選ぶ・切り替える |
| **削除**（ゴミ箱） | ツールバー | 開いているチャットを削除（確認あり） |
| **添付**（クリップ） | ツールバー | このチャットにPDF、TXT、Markdownファイルを追加 |
| **送信**（紙飛行機） | メッセージ欄の横 | メッセージを送る |
| **停止**（赤い四角） | 返信を書いている間、送信の代わりに表示 | 返信を止め、そこまでの内容を残す |
| **コピー** | 返信の下 | 返信をコピー |
| **再生成** / **再試行** | 最後の返信の下 | 最後の返信を書き直す / エラーの後にもう一度試す |
| **続ける** | 途中で切れた返信の下 | 返信を最後まで書く |
| **最新へ移動** / **返信を追う** | 上にスクロールしたとき、ツールバーの上 | チャットのいちばん下に戻る |
| 🗑 | チャット一覧の各チャット | そのチャットを削除（確認あり） |
| ドキュメントのチップの **×** | メッセージ欄の上 | そのドキュメントをこのチャットから外す |
| **思考過程** | 考えるモデルの返信の上 | モデルの推論を表示・非表示 |

スマートフォンでは、**削除** と **添付** はアイコンだけが表示されます。

## キーボードショートカット

| キー | パソコン | スマートフォン・タブレット |
|---|---|---|
| **Enter** | 送信 | 改行 |
| **Shift+Enter** | 改行 | — |
| **Ctrl+Enter** / **Cmd+Enter** | 送信 | 送信（キーボード使用時） |
| **Escape** | チャット一覧やダイアログを閉じる | — |
| **Tab** | 操作部品の間を移動 | — |

## よく使う操作

| やりたいこと | 操作 |
|---|---|
| 質問する | メッセージ欄に入力し、**Enter** を押すか **送信** をタップ |
| 新しく始める | **+** をタップ |
| 前のチャットを探す | **☰** → **チャットを検索** に入力 |
| 短く事実だけの答えがほしい | ペルソナメニュー → **🎯 的確** |
| 文章作成を手伝ってほしい | ペルソナメニュー → **✍️ ライター** |
| ファイルについて質問する | **添付** → ファイルを選ぶ → 質問する |
| 返信を速くしたい | 小さいモデルを選ぶか、速さの表示の提案をタップ |
| 回答の質を上げたい | 大きいモデルを選ぶ（**設定 → モデル選びを手伝って** → 高性能） |
| 長い返信を許したい | **設定 → 返信 → 最大トークン数** |
| 意味不明な返信を直したい | 警告の **モデルを切り替える** をタップするか、**32-bit** のモデルを選ぶ |
| アプリの言語を変えたい | **設定 → 言語** |
| チャットをバックアップしたい | **設定 → チャットをエクスポート** |
| チャットを別のデバイスに移したい | ここで「チャットをエクスポート」→ 移行先で **チャットをインポート** |
| アプリをインストールしたい | **設定 → このデバイス → アプリをインストール**（iPhone/iPad: Safariの **共有 → ホーム画面に追加**） |

## 覚えておきたいこと

* 🔒 すべてデバイスの中にとどまります。入力した内容はどこにも送られません。
* 💾 チャットは自動で保存されますが、このブラウザの中だけです。バックアップにはエクスポートしてください。
* ✈️ ダウンロード済みのモデル（✓）なら、オフラインで使えます。
* ⚠️ AIは間違えることがあります。大切な事実は確認してください。
