# 7. 設定

[← モデルを選ぶ](06-models.md) · [マニュアルのトップ](README.md) · [次へ: オフラインとバックアップ →](08-offline-and-backup.md)

ヘッダー右上の **⚙** をタップすると設定が開きます。**戻る** をタップするとチャットに戻ります。

> **変更は自動で保存されます。** 保存ボタンや適用ボタンはありません。ほとんどの変更は次のメッセージから反映されます。

> **ヒント:** 既定の設定はほとんどの方に適しています。返信の動きを細かく調整したいときだけ、この章を読めば十分です。

## モデル

* **モデルメニュー**: 55のモデルから選びます。メニューの下にモデルの正式な技術名が表示されます。
* **モデル選びを手伝って**: 2つの質問で選ぶモデル選択を開きます。

別のモデルを選ぶと、そのモデルのおすすめ返信設定も適用されます。詳しくは[モデルを選ぶ](06-models.md)をご覧ください。

## 外観

* **システム**（既定）は、デバイスのライト・ダークの設定に合わせ、デバイスの設定が変わると一緒に変わります。
* **ライト** または **ダーク** は、デバイスの設定にかかわらず常にそのテーマを使います。

## 言語

アプリ自体（ボタン、メニュー、メッセージ）の言語です。Hearthは英語、インドネシア語（一覧では Indonesia）、日本語で使えます。

* **自動**（既定）は、Hearthがブラウザの言語に対応していればその言語を、そうでなければ英語を使います。選ばれた言語がかっこ内に表示されます。
* または一覧から言語を選びます。各言語はその言語自身の表記で書かれているので、日本語は **日本語** と表示されます。

変更はすぐに反映され、このデバイスに記憶されます。AIの返信の言語は変わりません。AIはあなたが書いた言語で返信します。

使いたい言語がありませんか？ **Hearthの翻訳に協力する** から、言語を追加するためのガイドを開けます。

## 返信

### 温度

**返信がどのくらい創造的か、予測しやすいか。** 範囲は0.0〜2.0。

| 設定 | 効果 | 向いている用途 |
|---|---|---|
| 低い（0.0〜0.4） | 焦点が定まり、一貫して予測しやすい | 事実、コード、手順の説明 |
| 中くらい（0.5〜0.9） | バランスが良い | 日常のチャット |
| 高い（1.0以上） | 変化に富み意外性があるが、とりとめがなくなったり作り話をしたりすることも | アイデア出し、創作 |

### 最大トークン数

**1回の返信の最大の長さ。** 範囲は16〜2048 *トークン*。トークンは単語の一部で、100トークンは英語でおよそ75語、日本語では100〜200文字ほどです。スライダーの横におおよその語数が表示されます。

* 小さすぎる: 返信が途中で打ち切られます。続きを書かせる **続ける** ボタンが表示されます。
* 大きくする: 長い返信ができますが、長い返信は書くのに時間がかかります。

既定値はモデルの大きさによって決まります（最小のモデルで256、3B以上で1024）。コンテキストウィンドウの半分より大きくはできません。

### コンテキストウィンドウ

**会話のうち、モデルが一度に「覚えて」いられる量。** 範囲は512〜8192トークン。

* 大きくする: 長いチャットをより多く覚え、添付したドキュメントもより多く読めますが、GPUメモリを多く使います。
* 小さくする: メモリの使用は減りますが、長いチャットの前半を早く忘れます。

モデルの**再読み込み**が必要なのはこの設定だけです。変更すると *「保存しました。使うにはモデルの再読み込みが必要です…」* と表示されます。**今すぐモデルを再読み込み** をタップするとすぐに適用され（数秒かかります）、タップしない場合は次にアプリを開いたときに適用されます。

### 推論モデルに先に考えさせる

既定は **オフ** です。**オン** にすると、Qwen3とQwen3.5のモデルが答える前に段階的に推論します。難しい質問（数学、論理、計画）に役立つことがありますが、遅くなり、返信の長さの一部も使います。推論の内容は、折りたたみ式の **思考過程** の見出しの下に表示されます。DeepSeek-R1のモデルは、この設定にかかわらず常に推論します。

### 詳細なサンプリング

既定では折りたたまれています。*ほとんどの人には必要ありません。* **詳細なサンプリング** をタップすると開きます。

| 設定 | 範囲 | わかりやすく言うと |
|---|---|---|
| **Top P** | 0.01〜1.0 | 小さくすると、モデルは最もありそうな言葉を選ぶようになります。 |
| **頻度ペナルティ** | −2〜2 | 大きくすると、同じ言葉の繰り返しが減ります。 |
| **存在ペナルティ** | −2〜2 | 大きくすると、新しい話題を出しやすくなります。 |
| **繰り返しペナルティ** | 1.0〜2.0 | 大きくすると、前の文章の繰り返しが減ります。返信が同じことを繰り返すときは少し上げてください。 |

### このモデルのおすすめ設定に戻す

温度、最大トークン数、コンテキストウィンドウ、詳細な設定を、現在のモデルのおすすめ値に戻します。確認が表示されます。ペルソナとカスタムの指示は変わり**ません**。

## ペルソナ

* **新しいチャットの既定**: 新しいチャットで最初に使うペルソナ。
* **…の指示を表示**: ペルソナに与えられている指示を読めます。
* **🛠 カスタムペルソナ**: 自分で指示を書きます。**「フレンドリー」の指示に戻す** で出発点を入れられます。

詳しい説明とコツは[ペルソナ](04-personas.md)をご覧ください。

## ドキュメント

* **アップロードの最大サイズ**: 添付できるファイルの最大サイズで、1〜200 MB（既定は50 MB）。中のテキストは常に約200ページまでです。

[ドキュメントについて質問する](05-documents.md)をご覧ください。

## このデバイス

アプリが確認した、ブラウザとグラフィックスチップの情報です。主に[トラブルシューティング](09-troubleshooting.md)のときに役立ちます。

| 項目 | わかること |
|---|---|
| **WebLLMのバージョン** | アプリが使っているAIエンジンのバージョン |
| **GPU** | お使いのグラフィックスチップ、または *WebGPUを利用できません* |
| **16ビットGPUのサポート** | GPUが速い16ビットモデルに対応しているか |
| **チャットの保存先** | チャットの保存場所。ここに警告がある場合は、ストレージが限られています（プライベートブラウズなど）。 |
| **オフラインで動作** | アプリがオフライン用に保存されているか |
| **アプリ** | ブラウザが対応していれば **アプリをインストール** ボタン、または *インストール済み* |
| **16ビット（q4f16）モデル** | 16ビットモデルがここで正しく動くか |

お使いのデバイスで自動の品質チェックに失敗したモデルがあれば、文字化けした出力の例と一緒に **ここでモデルのチェックに失敗したもの** の下に表示されます。

**チェック結果を消去** で結果を消すと、各モデルがもう一度チェックされます。ブラウザやグラフィックスドライバーを更新した後に便利です。

## エクスポート / インポート

| ボタン | 動作 |
|---|---|
| **設定をエクスポート** | 設定を `hearth-settings-YYYY-MM-DD.json` という名前のファイルとしてダウンロードします。 |
| **設定をインポート** | エクスポートしたファイルから設定を読み込みます。現在のモデルの選択は保たれるので、インポートで思わぬダウンロードが始まることはありません。 |
| **チャットをエクスポート** | すべてのチャット（添付したドキュメントを含む）を `hearth-chats-YYYY-MM-DD.json` としてダウンロードします。 |
| **チャットをインポート** | エクスポートしたファイルのチャットを、今あるチャットに追加します。既にあるチャットはスキップされるので、重複や上書きはありません。 |

手順は[データのバックアップと移行](08-offline-and-backup.md#データのバックアップと移行)をご覧ください。

> **メモ:** **外観** と **言語** の選択はこのデバイスだけに保存され、エクスポートには含まれません。

## 現在のチャット

* **会話を削除**: 開いているチャットを、メッセージと添付ドキュメントごと削除します。削除の前に確認します。

設定のいちばん下には、アプリの名前とバージョン、ソースコードへのリンク、アプリの基盤となっているエンジンWebLLMへのリンクがあります。

> **重要:** チャットの削除は元に戻せません。あとで必要になりそうなチャットは、先にエクスポートしてください。
