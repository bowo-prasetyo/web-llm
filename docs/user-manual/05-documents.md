# 5. Asking about your documents

[← Personas](04-personas.md) · [Manual home](README.md) · [Next: Choosing a model →](06-models.md)

You can attach a document to a chat and ask questions about it, such as *"Summarize this report"* or *"What does the contract say about cancellation?"* The file is read inside your browser and **never leaves your device**.

## Supported files

| Type | Extensions |
|---|---|
| PDF | `.pdf` (must contain real text, see below) |
| Plain text | `.txt` |
| Markdown | `.md`, `.markdown` |

**Limits:**

* File size: up to **50 MB** by default. You can raise it to 200 MB in **Settings → Documents → Max Upload Size**.
* Text length: up to about **500,000 characters (roughly 200 pages)** per document.

> **Note:** Scanned PDFs (photos of pages) have no text layer, so the app can't read them. If you can't select text in the PDF with your mouse, it's probably a scan.

## Attach a document

1. Open the chat you want to use (or start a new one).
2. Tap **Attach** (paper-clip icon) in the toolbar.
3. Choose your file.

The file appears as a **chip** above the message box with its name, size, and a status while it's being read or prepared. When the status settles, it's ready.

You can attach more than one document to the same chat.

## Ask about it

Just type your question as usual. For example:

* *"Summarize this document in five bullet points."*
* *"What are the payment terms?"*
* *"List every date mentioned and what happens on it."*
* *"Explain section 3 in plain English."*

The app automatically gives the assistant the relevant parts of your document with each question.

## How it works (in plain words)

* **Short documents** are handed to the assistant **in full** with every question.
* **Long documents** are too big to give the assistant all at once. Instead, the app splits them into small passages and, for each question, picks the passages that best match what you asked. The first time you attach a long document, the app downloads a small search helper (about 23 MB, once only).
* **General requests** like *"summarize this"* don't match one part in particular, so the assistant gets the beginning of each document instead.

> **Tip:** For long documents, specific questions work best. *"What does it say about refunds?"* finds the right passage more reliably than *"Tell me everything."* For an overall summary of a very long file, ask about one section at a time.

## Attachments belong to one chat

* A document attached to one chat is **only** used in that chat. Other chats can't see it.
* It's saved with the chat, so it's still there when you reopen the chat later.
* It's deleted, exported and imported together with the chat.
* A chat that has only a document and no messages yet is still kept in your list, titled with 📎 and the file name.

## Remove a document

Tap **×** on the document's chip. It's removed from this chat only.

## Documents from older versions

If you used an earlier version of the app, you may see a note saying documents you added before *"were shared by all chats and are no longer used."* Attach the files you need to individual chats, then tap **Remove them** to clear the old copies.

## Privacy

Attached files are read and searched entirely on your device. They're stored in your browser together with the chat and are never uploaded anywhere.
